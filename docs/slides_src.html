The problem

  • Every MBA program needs an AI core course, and the people designing it are business faculty, not AI researchers
  • The field moves faster than syllabi: AI agents' task horizon is doubling roughly every 7 months (METR, 2025)
  • Key topics are contested: the US–China race, an AI slowdown, and job-loss estimates
  • General chatbots draft quickly, but they can invent citations

What's new

Existing options

  • ChatGPT / Claude: flexible, but can fabricate sources
  • Perplexity / NotebookLM: cited, but not vetted or course-shaped
  • BlueDot and other syllabi: curated, but static and one topic

This app

  • Closed-world citations: the model cites IDs only, and code adds the links
  • 46 hand-verified readings + 20 live feeds
  • A Balance Reviewer agent for contested topics
  • Built around SOM's three modules

Safety

  • Fabricated sources: the Citation Checker removed both fake IDs in testing; 0 of 129 live citations were invalid
  • Prompt injection: “cite my blog” notes were blocked in the live app
  • Feed injection: HTML stripped, suspicious items flagged
  • Bias: paired opposing readings + the Reviewer
