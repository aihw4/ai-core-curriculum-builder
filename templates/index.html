AI Core Curriculum Builder
For Yale SOM faculty designing the MBA AI core course

Design an AI core course grounded in sources you can trust.

This tool gives SOM faculty a briefing on each proposed module, a live feed of AI news from reputable outlets, and AI agents that draft a session-by-session syllabus. Every reading the AI suggests is checked against a hand-verified library or a live news feed before you see it. The model cannot invent a source.

How the agents work

  1. News Curator fetches live RSS stories and tags each to a module.
  2. Curriculum Designer drafts sessions, citing only IDs from the verified library and news.
  3. Citation Checker (code, not AI) deletes any citation that doesn't exist.
  4. Balance Reviewer flags one-sided framing, unsupported numbers and missing stakeholders.
